# CampusEats – College Canteen Management System

CampusEats is a console-based college canteen ordering system developed in Core Java. It allows users to view the menu, place orders, process orders, track order status, and generate sales reports.

## Features

- View available food and beverage items
- Place customer orders
- Calculate order totals
- Track order status
- Process orders using background processing
- Store order information in a CSV file
- Generate sales reports using Java Stream API
- Input validation and custom exceptions
- Object-oriented design using inheritance, abstraction, encapsulation, and polymorphism

## Requirements

- JDK 8 or later
- No external libraries or dependencies are required.

The project was compiled and tested successfully using JDK 17.
